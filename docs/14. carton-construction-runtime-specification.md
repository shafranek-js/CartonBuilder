# Carton construction runtime specification

Wave 8B adds two structural mockup templates to the canonical `BoxNetModel`:
Straight Tuck End (`ste`) and Reverse Tuck End (`rte`). `legacy-six-panel`
remains the default and is used by the bundled `Calmdownol_template.carton`.

## Canonical state and compatibility

Project schema is v14; archive manifest remains v4. The board caliper continues
to live in `box.board.caliperMm`. Parametric projects additionally store:

```js
box.construction = {
  templateId: 'legacy-six-panel' | 'ste' | 'rte',
  templateVersion: 1,
  parameters: { glueTabWidthMm, tuckTabDepthMm, dustFlapReachMm, lockEarMm }
}
```

`box.elements` contains polygon elements with role, surface key, hinge,
assembly phase and overlap layer. `getPanels()` remains the six-surface
compatibility API; `getElements()`/`getElement()` expose the full construction.
Schema v13 snapshots migrate to legacy-six-panel without moving artwork.
Box presets use format v2 and retain construction; Render/View presets do not.

## Templates and assembly

Both templates generate four body surfaces, two closures, two tuck flaps, four
dust flaps and one glue tab. Parameters are sanitized against dimensions and
the board caliper. The Preview slider uses staged assembly: body, glue seam,
bottom dust/closure/tuck, then top dust/closure/tuck. Technical Preview remains
flat; Studio and Photorealistic use thickness-aware polygon solids. Render,
PNG/JPG, GLB, turntable and standalone HTML use the closed solver state.

The overlap order is body → glue seam → dust → closure → tuck. Intersections
reported by diagnostics distinguish expected overlap layers from invalid
polygon/hinge state. A structural mockup is not an ECMA/FEFCO-certified
production dieline; production allowances remain Wave 9.

## 2D and export boundaries

Dielines are derived from polygon perimeters and hinge records. Shared lines are
fold lines and outer lines are cut lines; SVG/PDF include flap geometry and the
explicit structural-mockup notice. Artwork clipping and UVs use the same full
flat-net polygon space across body, closure and tuck elements. HDRI/backplates
remain external to GLB.

Transient geometry diagnostics include template/version, element count, staged
assembly label, effective caliper/bevel, hinge gap, clearance and invalid
intersection metadata. They are not persisted in project snapshots.
