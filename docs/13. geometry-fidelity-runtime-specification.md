# Geometry Fidelity runtime specification

## Canonical board construction

`BoxNetModel.board.caliperMm` is the single source of truth for board caliper.
The default is `0.35 mm`; accepted values are `0.01–2.00 mm`, additionally
limited to one quarter of the smallest box dimension. The Create Box field and
Render board control edit this same value. Box presets include it; Render/View
presets do not override it. `renderAppearance.thicknessMm` remains a computed
compatibility mirror for older adapters and snapshots.

Project schema v13 migrates v12 by taking the old
`renderAppearance.thicknessMm` value when present, otherwise `0.35`. Archive
manifest v4 is unchanged and no binary asset is introduced. Technical 2D
exports and the dieline remain nominal flat dimensions.

## Thickness-aware geometry

Technical Preview uses the exact flat panel geometry. Studio and Photorealistic
Preview, closed Render, GLB, turntable and standalone HTML use the same solid
panel construction. Exterior and interior surfaces are placed at `+/-caliper/2`;
child hinge anchors are offset from the exterior crease line to the matching
surface. This keeps the crease line coincident at Open, Half and Closed fold
progress. Solid panels have an exterior artwork cap, inset interior cap and
material-separated edge faces. Bevel is bounded by
`min(requested, caliper * 0.45, panelMin / 8)`.

Artwork UVs continue to use the original flat-net coordinates, so artwork that
crosses a fold has no geometry-induced UV seam. Render is always closed and has
no assembly slider; Preview preserves its existing fold slider.

## Diagnostics and recovery

Geometry diagnostics are transient and exposed with renderer diagnostics:
requested/effective caliper and bevel, maximum hinge gap, non-adjacent volume
intersections, and world-space 3D bounds. They are not written to project or
preset snapshots. Rebuilding after a mode, dimension or caliper change keeps the
current camera and fold progress. WebGL recovery restores the active geometry
from the canonical model.

## Boundaries

Glue/tuck/dust flaps, lock tabs, free-angle collision simulation, a construction
library and production crease allowance are not part of this contract; they are
Wave 8B/9 work. SVG/PDF technical output remains unchanged.
