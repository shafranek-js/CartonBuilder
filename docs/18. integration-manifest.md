## 8. Фиксация исправленного Этапа 1B (Plugin Packaging and Vendoring)

Дата верификации: 2026-08-21

### 8.1. Контракты манифестов

* `plugin.manifest.v1` описывает один самостоятельный plugin package и не
  является каталогом.
* `plugins.manifest.v1` описывает host-каталог. Каждая запись содержит
  канонический `manifestPath`, byte length/SHA-256 самостоятельного манифеста и
  полную семантическую копию plugin descriptor.
* Host валидирует обе schema до вычисления destination и до любых изменений
  файловой системы. `id` и `version` дополнительно проверяются как одиночные
  безопасные сегменты, а итоговый путь обязан оставаться внутри
  `vendor/plugins`.

### 8.2. Producer artifact и provenance

* PBD source commit: `6293cc98d743369275a42049fbc359a0d9a8bb6d`.
* Plugin entrypoint: `583,947` байт,
  SHA-256 `6087faed708b4e3f8edd3ff0eb67fce74a2cd0c9ae5856e19166748b2d5dc78e`.
* Standalone manifest SHA-256:
  `3e4452053576ed80edfebc4ae3b8947fce1ba2eec9217d8cba507b23e2eae154`.
* Официальный PBD plugin builder запускается только при совпадении tracked
  inputs с `HEAD`; сгенерированный release HTML дополнительно сверяется с
  committed artifact byte-for-byte.
* Plugin HTML получает реально применяемую CSP, а sandbox policy не использует
  опасную same-origin комбинацию: только `allow-scripts`.

### 8.3. Transactional vendoring и build integrity

* `plugins:sync:pbd` полностью выполняет preflight plugin package, embedded
  workflow package и будущего каталога до мутаций.
* Plugin directory, `src/workflow` и `plugins.manifest.json` активируются одной
  multi-target transaction. Ошибка любого rename восстанавливает все ранее
  заменённые назначения.
* `plugins:verify` сверяет самостоятельный manifest с каталогом, его собственный
  SHA-256, все plugin files, entrypoint/artifact, embedded contract, CSP,
  отсутствие лишних файлов и статических внешних URL.
* Vite использует `vendor` как `publicDir`, поэтому проверенные плагины входят в
  публикуемый `dist/plugins`; production build не обращается к соседним
  `C:\Projects\...`.
* Статический scanner не объявляется доказательством runtime offline сам по
  себе. Playwright отдельно загружает опубликованный PBD и требует ноль внешних
  запросов.
