### 8.3. Transactional vendoring и build integrity

* `plugins:sync:pbd` полностью выполняет preflight plugin package, embedded
  workflow package и будущего каталога до мутаций.
* Plugin directory, `src/workflow` и `plugins.manifest.json` активируются одной
  multi-target transaction. Ошибка любого rename восстанавливает все ранее
  заменённые назначения.
* `plugins:verify` сверяет самостоятельный manifest с каталогом, его собственный
  SHA-256, все plugin files, entrypoint/artifact, embedded contract, CSP,
  отсутствие лишних файлов и статических внешних URL.
* Vite использует `vendor` как `publicDir`, поэтому проверенные плагины входят в
  публикуемый `dist/plugins`; production build не обращается к соседним
  `C:\Projects\...`.
* Статический scanner не объявляется доказательством runtime offline сам по
  себе. Playwright отдельно загружает опубликованный PBD и требует ноль внешних
  запросов.
