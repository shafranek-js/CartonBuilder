## 5. Целевые требования интеграции (Target Architecture)

1. **Контракт обмена**:
   * Версионированный bundle: `carton-workflow.v1`
   * Каноническая семантическая модель: `pbd.model.v1`
   * Производная SVG-развёртка: `pbd.svg.v4`
2. **Изоляция и сборка (Release 2 / Release 3)**:
   * **Three.js локально, версия 0.185.1 без CDN** — обязательное целевое требование для будущего Viewer `2.4.0` (текущий Viewer `2.3.0` использует Three.js `0.180.0` через CDN как reference baseline).
   * Никаких сетевых запросов или обращений к `C:\Projects\...` из CI/build.
   * Детерминированная команда синхронизации готовых артефактов в `vendor/plugins/` с проверкой SHA-256 и версий.
3. **Безопасность host-протокола**:
   * Валидация `origin`, `sessionId`, `contractVersion`, размера payload и `sha256`.
