# Prepress Foundations Runtime Specification

Wave 9A adds a derived production-assist proof without mutating the canonical
box, artwork transforms or 3D render geometry. Project schema v15 stores the
`prepress` settings; archive manifest remains v4 and contains no new binary
assets.

## Modes and settings

`technical-proof` is the compatibility default. `production-assist` enables
bleed, safe and slug measurements plus manual cut/crease/glue/tuck allowances.
Bleed and safe are clamped to 0–20 mm, slug to 0–30 mm, and offsets are clamped
to the ranges in `prepressState.js`. Legacy Custom Net accepts bleed/safe/marks
but shows a manual allowance warning.

## Derived dieline

`buildProductionDieline()` constructs trim polygons, external bleed offsets,
safe insets, stable cut/fold segments and media bounds. Invalid polygons block
only prepress export. The production model is never written back to
`BoxNetModel`, `ArtworkModel`, Preview or Render state.

For `production-assist`, glue-tab deltas expand away from the hinge and tuck
clearance symmetrically reduces the free tuck outline while preserving the
hinge and depth. Cut offsets are applied to closed contours; an ambiguous or
open topology blocks export. Technical-proof geometry ignores all production
allowances. Structural texture masks use `getElements()` so glue, tuck and
dust flaps are covered together with body panels.

## UI and diagnostics

Artwork contains a Prepress panel for mode, profile, bleed/safe/slug, DPI,
allowances and marks. View exposes independent Trim, Bleed, Safe, Dieline and
Marks overlays. `runPrepressPreflight()` returns transient Blocking, Warning and
Manual review categories and can be downloaded as JSON. Raster DPI below 150 is
blocking; 150–299 warns; vector/PDF artwork is exempt from raster DPI checks.
The cached report carries an input signature derived from the box, artwork
metadata and prepress settings; PDF, SVG and report exports always recompute
against the current signature.

## Exports and boundaries

Existing Technical Proof PDF is unchanged. Prepress PDF and SVG are separate
exports with named Artwork, CutContour, Crease, Bleed, Safe, Marks and Slug
layers/groups. PDF page boxes are sourced independently from trim, bleed and
media bounds; embedded artwork is inside the Artwork OCG and SVG artwork is
rasterized at `requiredDpi`, clipped to bleed and transformed for crop,
opacity, rotation and flip. CutContour and Crease use configured spot
separations; technical overprint uses `/OP true`, `/op true`, `/OPM 1` only
when enabled. The output is explicitly not PDF/X certified and not a contract
colour proof. PNG/JPG, GLB, turntable, standalone HTML and Render do not
consume production allowances.

Wave 9B remains responsible for ICC/Output Intent, PDF/X, trapping, vendor
profiles, font/barcode validation and production certification.
